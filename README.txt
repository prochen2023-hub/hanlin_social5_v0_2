帳號安全說明：
這是純前端、本機帳號。PIN 以瀏覽器 Web Crypto SHA-256 + salt 雜湊保存，但資料仍只存在 localStorage，適合家庭/單一裝置學習，不是可跨裝置或可找回密碼的正式雲端會員系統。
若未來需要跨裝置同步，請改接 Firebase Auth / Supabase Auth 或自有後端。
