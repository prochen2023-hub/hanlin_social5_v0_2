### 第一單元改成真正的視覺／互動教材

#### 第一課｜從地圖探索位置與發展有何關聯？
1. **世界 → 東亞定位**：公開授權真實世界／東亞底圖，一次只問一題、每題 3 個選項。
2. **臺灣範圍與離島**：臺灣區域圖、約 3.6 萬 km²、主要離島與海洋國家發展線索。
3. **季風 × 在地生活**：冬季東北季風、夏季西南季風，連結澎湖菜宅、蘭嶼地下屋、新埔柿餅、金門風獅爺、嘉義／臺南沿海養殖。
4. **洋流・漁獲・候鳥**：春夏黑鮪魚、冬季烏魚、黑面琵鷺與東亞候鳥遷徙中繼站。
5. **圖像闖關**：一次只顯示一題，盡量搭配地圖／照片。
6. **錯題救援**：只處理真正答錯的觀念。

#### 第二課｜史前人們如何善用資源維持生活？
- 史前時代、遺物／遺跡。
- 舊石器 → 新石器 → 金屬器時間軸。
- 長濱文化—八仙洞、卑南文化—卑南遺址、十三行文化—十三行遺址。
- 從打製石器、磨製石器、陶器、鐵器、聚落等證據推回生活方式。
- 生產力提高 → 定居／分工 → 交換擴大。
- 臺灣玉：花蓮豐田玉材 → 加工 → 全臺／澎湖 → 東南亞跨海交換。
- 十三行外來陶器、青銅器、錢幣、玻璃珠等交流線索。
- 5W1H 遺址探究＋八仙洞、卑南遺址、十三行博物館延伸。

#### 第三課｜原住民族文化與環境有何關聯？
- 16 族完整認識，但不要求全部死背。
- 地圖只呈現「傳統分布區域感」，明示現代族人分布更廣。
- 考前優先抓阿美、泰雅、布農、排灣、賽夏、邵、達悟等常見線索。
- 傳說／祭儀不是孤立配對，而是連結環境、祖先記憶、規範與族群價值。
- 打獵時序、飛魚規範、共享互助、共同決策與永續資源。
