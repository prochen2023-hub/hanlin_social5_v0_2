### 第一單元｜藏寶局變成真正的「過關遊戲」
- 棋格不再直接寫出黑鮪魚、黑面琵鷺、十三行、阿美族等答案，改用「春夏漁汛、濕地訪客、河口鐵村、東部部落」等線索名稱。

- 每局由 12 回合增加為 **15 回合**；棋盤字體、中央題目與手機按鈕放大，手機寧可水平滑動也不把文字壓成小字。

### 第二單元｜完整內容庫＋「大航海航路任務局」
第二單元不只做年代題，而是先補成兩課知識庫，再轉成遊戲。

**2-1 臺灣為什麼在大航海時代崛起？**
- 400 多年前的航海技術與東亞海上活動。
- 歐洲市場、東南亞據點、菲律賓、中國沿海、日本與臺灣的航路關係。
- 1624 荷蘭進入南臺灣、1626 西班牙進入北臺灣、1642 北部勢力轉折。
- 台江內海、熱蘭遮城、普羅民遮城、基隆／淡水據點。
- 招募漢人、稻米／蔗糖生產、鹿皮與蔗糖貿易，以及大量捕獵可能造成的生態壓力。
- 1661 鄭成功攻臺、1662 荷蘭退出；鄭氏把臺灣作為反清基地、海上交通與貿易據點，並以軍屯增加糧食。
- 新營、左營等「營」地名作為軍屯歷史線索。

**2-2 大航海時代在臺灣留下哪些影響？**
- 城堡、地名、羅馬字原住民族文書、宗教與學校等歷史痕跡。
- 鄭氏與日本、東南亞、中國沿海的貿易帳本：蔗糖、鹿皮、銀、軍火物資、香料等。
- 孔廟／儒學教育、漢人移民帶來的媽祖與玄天上帝等信仰。
- 土地開墾、人口移動與原住民族土地／文化受到的影響，要求孩子用多族群觀點思考。
- 1683 鄭氏政權結束，1684 清帝國正式將臺灣納入版圖，避免把兩年混成同一件事。

### 大航海航路任務局
- 24 格、15 回合；收集航線／據點、貿易貨物、古堡／史料、文化線索。
- 棋格同樣只給線索，例如「西南天然港、南方第一堡、北方港島、海上帳本、雙文字契約」，答對才解鎖答案。
- 每個一般格至少 4 題，同格重踩會優先換題。
- 題庫混合航路背景、荷蘭與貿易、西班牙北臺灣、鄭氏經營、文化社會影響與時序轉折。

#### 第二課｜史前人們如何善用資源維持生活？
- 史前時代、遺物／遺跡。
- 舊石器 → 新石器 → 金屬器時間軸。
- 長濱文化—八仙洞、卑南文化—卑南遺址、十三行文化—十三行遺址。
- 從打製石器、磨製石器、陶器、鐵器、聚落等證據推回生活方式。
- 生產力提高 → 定居／分工 → 交換擴大。
- 臺灣玉：花蓮豐田玉材 → 加工 → 全臺／澎湖 → 東南亞跨海交換。
- 十三行外來陶器、青銅器、錢幣、玻璃珠等交流線索。
- 5W1H 遺址探究＋八仙洞、卑南遺址、十三行博物館延伸。

#### 第三課｜原住民族文化與環境有何關聯？
- 16 族完整認識，但不要求全部死背。
- 地圖只呈現「傳統分布區域感」，明示現代族人分布更廣。
- 考前優先抓阿美、泰雅、布農、排灣、賽夏、邵、達悟等常見線索。
- 傳說／祭儀不是孤立配對，而是連結環境、祖先記憶、規範與族群價值。
- 打獵時序、飛魚規範、共享互助、共同決策與永續資源。
