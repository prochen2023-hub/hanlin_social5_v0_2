- 從打製石器、磨製石器、陶器、鐵器、聚落等證據推回生活方式。
- 生產力提高 → 定居／分工 → 交換擴大。
- 臺灣玉：花蓮豐田玉材 → 加工 → 全臺／澎湖 → 東南亞跨海交換。
