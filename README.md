這個資料夾就是 GitHub Pages `deploy` branch 的網站根目錄，可直接作為 Pages publishing source。

## 已完成內容

- 本機多帳號登入：暱稱 + PIN
- 第一～第五單元全部開放：共 13 個學習任務，每課完整六關
- 每課至少 7 個核心重點，並保留配對、故事、找證據、闖關、救援
- 全站課文與題目支援 🔊 zh-TW 系統人聲朗讀
- 第一次段考模擬 A / B 卷：各 100 分、40 分鐘、7 類真實紙筆題型
- 弱點救援與錯題回流
- 時光機、星星與成就系統
- 手機單欄介面

## 資料保存方式

帳號、PIN、星星、錯題與進度目前儲存在瀏覽器 `localStorage`，不會跨裝置同步。清除瀏覽器網站資料後，這些本機紀錄也會消失。

## GitHub Pages

請在 Repository → Settings → Pages 設定：

- Source: `Deploy from a branch`
- Branch: `deploy`
- Folder: `/(root)`

詳細步驟見 `DEPLOY_BRANCH.md`。
